On 2026-10-07 the isolated dependency-complete checkout passed all 345 tests with auth-first activation controls, worker observation fencing/hierarchy rendering, sliders and waiting-goal pause controls. All 14 focused UI/media checks pass, including seven setup checks and three loading checks. The rebuilt normal portable launcher also passes exact payload identity and the loading transitions. Candidate hashes and sanitized results are in [journey-acceptance.json](journey-acceptance.json). Root checkout incomplete dependencies do not qualify a full-suite pass.

Actual packaged checks use isolated account-free profiles. First launch verifies bundled Modal/Fly availability with host CLIs absent from PATH, renderer isolation, all six decoded video/audio cues and clean window shutdown. The revised seven-second Fly cue reaches its natural end. A separate setup-completion fixture verifies unlimited 100-Worker/10-conversation settings, finite budget/RAM edits, deletion and clean shutdown. Waiting-goal pause/resume also passes in actual packaged Electron. A historical Worker fixture renders two nodes and their parent edge after restart with zero active nodes. Native and normal portable runs perform zero provider calls, zero cloud mutations and verify zero deployed Workers.

An additional actual packaged read-only check recognizes the existing Modal account session without signing in, toggles Modal off/on/off, preserves deselection through provider discovery, verifies dialogue placement inside the modal and closes through the window-corner X with private authority files removed. It performs no inference or cloud mutation. Offline checks additionally verify that the initial parallel auth checks finish before activation buttons appear, activation clicks make no auth/discovery/disconnect call, completion preserves the chosen providers and New Swarm uses only activated providers.

Media originals, extracted audio/subtitles, caches, account files, private test profiles and runtime receipts remain outside public Git. Only public source, attribution, lock metadata and sanitized acceptance claims belong here. No fresh login, paid inference, Source startup, native subscription fleet activation or public release is qualified by these checks.
