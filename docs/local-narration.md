# Local narration

Seagulled warms a CPU Kokoro narration worker when voice capabilities are first requested, alongside local speech recognition. Narration uses the packaged `am_michael` preset, not Todd Howard's recorded or cloned voice. The installed Windows voice remains available while public model weights warm or when the local model fails. The renderer receives the actual current narration source and readiness separately from recognition readiness; it should describe these only in Advanced.

Kokoro.js is pinned to 1.2.1 in the package lock. Its compatible Transformers.js model classes and tokenizer load `onnx-community/Kokoro-82M-v1.0-ONNX` at revision `1939ad2a8e416c0acfeecc08a694d14ef25f2231`, q8 CPU, with four inference threads. The preset voice vectors ship in the dependency. The model downloads only public artifacts to the user's private application cache; goal text is synthesized locally and does not enter a hosted TTS request. Both Transformer versions use the same patched Sharp 0.35.5 dependency through a global override; the nested override was replaced after GitHub CI exposed a clean-install lockfile mismatch. An isolated npm 10.9.4 clean-install dry run validates the new lock without executing dependency scripts.

Inference runs outside the Electron main thread, with a three-minute startup bound and one-minute narration bound. Stop terminates active inference and cancels warmup; an old worker's reply cannot become a new utterance. Closing the app terminates the worker. Short word-boundary chunks avoid model token truncation, and output is bounded to sixty seconds and converted to canonical mono 16 kHz PCM. The renderer continues to cancel playback independently.

Recognition and narration use one pinned native `onnxruntime-node@1.30.0` through a global override. A longer packaged check of the earlier dual-runtime checkpoint crashed when recognition requested ONNX API 30 after narration loaded runtime 1.21; separate worker threads share the process's native DLL namespace on Windows. The correction keeps each model's compatible Transformer classes while resolving both to the same native backend. A deterministic, offline two-worker regression runs concurrent CPU sessions using an authored 123-byte Identity graph. Actual source acceptance also loaded both pinned public models, synthesized 3.725 seconds of narration while recognizing the recorded fixture phrase, and verified recognition survives narrator retirement. Packaged sustained-voice acceptance remains a separate gate until the corrected build is checked.

Source acceptance on October 5, 2026 generated a 3.675-second utterance with the actual local model, after a 35.070-second first warmup, in 4.252 seconds. A separate actual Windows packaged Electron check reused those public cached weights, synthesized the same-duration utterance through preload IPC in 3.470 seconds, loaded the empty movie manifest, confirmed renderer isolation and shut down cleanly. Deterministic tests cover format conversion, saturation, malformed output, fallback, readiness, cancellation, stale replies and closing. These checks do not qualify physical microphone hardware, perceived voice quality, film lip synchronization or approved avatar footage; those remain separate checks.
