Seagulled is an independent, unofficial parody interface. Todd Howard's name is used as a fictional conversational persona; this project is not affiliated with him, Bethesda, Microsoft, Anthropic, OpenAI, Google, or Modal.

The FLUJO swarm engine in `upstream/swarm-teams` is a selected source extraction owned by flujo-app, pinned to commit `f9d372a66dd2cb09f4bcfed34967404cf12d9007`. Its original private repository remains separate. Public source contains no original account state, conversations, databases or deployment credentials. The extraction manifest records original file hashes; Seagulled changes are tracked in Git.

Factory supplied durable admission, ownership and accounting patterns. Its pure `src/receipts.mjs` helper is a byte-identical selected extraction under `upstream/factory/receipts.mjs`, pinned to `510b733f8af0305bb2969592fe25cc73549306a4`. Packaged Chromium and Node carry their upstream notices distributed with Electron.

Local voice recognition uses Apache-2.0 licensed Transformers.js and the Apache-2.0 licensed `Xenova/whisper-base` ONNX artifacts pinned to revision `64da57285918e20ea79ea5c88eed7197933abaa8`. Public model weights download to the user's private application cache; microphone recordings are processed locally. ONNX Runtime is MIT licensed. Native Windows narration uses the installed Windows speech engine and is not a recording or clone of Todd Howard's voice. The MIT licensed node-pty dependency provides Fly's private browser sign-in terminal. Dependency licenses ship with the corresponding packages.

These are public software dependencies, not copies of a developer's installed runtime or account configuration.
