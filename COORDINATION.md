# Release candidate contracts

Shared checkout: the current repository.

Providers: export discoverProviders(options?), ProviderManager from src/providers/index.mjs. Manager exposes discover(), connect({id,method,key?,model?}), disconnect(id), run({providerId,prompt,signal,onEvent,maxUsd,goalId,role}), publicState(). run returns {text,usage:{inputTokens,outputTokens,costUsd,costKind},providerId}; costKind is reported/estimated/unknown/subscription. onEvent carries safe text, usage or status only. discover and publicState never expose credentials. Native subscription CLIs use their own login state without copying tokens. Modal key/OAuth wizard must use real supported capabilities and acknowledge unsupported ones.

Swarm: export SwarmCoordinator from src/swarm/index.mjs. constructor({providers,onEvent,dataDir}); execute({goal,signal}) returns {text,usage,tasks}; goal is {id,text,budgetUsd,spentUsd,providerId,maxWorkers}. Use provider.run for bounded lead/developer/reviewer work; connect recovered FLUJO fleet when available without launching or modifying existing fleets. Emit {type:'task',goalId,task:{id,role,status,text?}}, {type:'message',goalId,role,text}, {type:'usage',goalId,usage}. Do not double count returned and emitted usage. Public summaries must remain honest about actual remote sandbox use. Expose Todd persona prompt for conversational frontend.

Runtime: parent exports createRuntime({dataDir,providers?,swarm?}). Methods snapshot(), chat(text), updateGoal(id,patch), controlGoal(id,action), discover(), connect(payload), disconnect(id), subscribe(listener), close(). All mutations persisted, controls cancel in-flight execution. HTTP server createServer({runtime}) binds loopback ephemeral port itself; exposes /api/state, /api/chat, /api/goals/:id PATCH, /api/goals/:id/:action POST, /api/providers/discover POST, /api/providers/connect POST, /api/providers/:id DELETE, /api/events SSE. Mutation authentication via per-process bootstrap token passed to Electron preload and CLI client; browser development uses token via URL fragment removed after bootstrap. UI uses window.seagulled bridge if present, otherwise authenticated fetch and SSE. Native bridge has state(), chat(text), updateGoal(id,patch), controlGoal(id,action), discover(), connect(payload), disconnect(id), onEvent(callback). Errors return clear human-readable messages.

State: {version:1,conversation:[{id,role,text,at,goalId?}],goals:[{id,text,status,budgetUsd,spentUsd,providerId,tasks,createdAt,updatedAt,error?}],providers:[{id,name,available,connected,methods,detail?,models?}],spend:{usd,unknownCalls,subscriptionCalls},swarm:{status}}. Events include {type:'state',state}, provider/task/message/usage events. UI must render full state and update spend on events. Parent supplies default 5 USD budget, capped 6 tasks. Budget edits finite positive; lowering below spend pauses.
