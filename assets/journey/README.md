# Journey media build inputs

These are the seven exact excerpts shipped in Seagulled 0.1.1, committed so a
fresh source checkout can package the app. `docs/journey-media-lock.json`
records each SHA-256, original video URL, start time and duration. The staging
script verifies every clip before copying it into the renderer and package.

Dialogue plays inside the setup modal. `starfield-loading.mp4` is the silent
81–86 second excerpt for startup and modal transitions. Full original downloads,
downloader metadata and account state are excluded. These are third-party
media, separate from the source MIT license; inclusion does not relicense the
original audiovisual works.
